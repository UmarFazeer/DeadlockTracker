# Deadlock Tracker

Deadlock Tracker is a web application for viewing player statistics from Valve's Deadlock.

The project is currently in early development.

## Current Goal

The first version of the application will allow users to:

- Enter a Steam name or ID
- Select a Ritualist 
- View player statistics for that Ritualist 
- View wins and losses
- View KDA
- View recent match history

## Tech Stack

### Frontend
- React
- TypeScript
- Vite

### Backend
- Node.js
- Express
- TypeScript

### Data
- Deadlock API
- https://deadlock-api.com/
